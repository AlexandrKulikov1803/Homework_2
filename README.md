### Модуль product.py

Класс ***Product*** содержит основную информацию о продукте:

+ Название продукта(str)
+ Описание(str)
+ Стоимость(float) - private
+ Количество(int)

А также ***список всех созданных продуктов(list)***.

В данном классе реализованы магические методы ***__str__*** и ***__add__***.

Метод ***__str__*** отображает информацию об объекте класса для пользователей в формате:

```
{Название продукта}, {стоимость} руб. Остаток: {количество} шт.
```

Например:

```
Samsung Galaxy S23 Ultra, 180000.0 руб. Остаток: 5 шт.

```

Метод ***__add__*** позволяет высчитать полную стоимость товаров на складе:

```
# Вызов метода
product_1 = Product("Samsung Galaxy S23 Ultra", "256GB, Серый цвет, 200MP камера", 180000.0, 5,)
product_2 = Product("Iphone 15", "512GB, Gray space", 210000.0, 8)
print(product_1 + product_2)

# Выходные данные
2580000.0
```

В классе имеется возможность добавлять новый продукт с помощью класс-метода ***new_product***. На вход подаётся словарь
с параметрами нового продукта. При этом поведение данного метода зависит от входных данных.

Пример №1.
Если передан новый продукт, которого ещё нет на складе, то метод возвращает новый продукт.

```
# Вызов метода
product_1 = Product("Samsung Galaxy S23 Ultra", "256GB, Серый цвет, 200MP камера", 180000.0, 5)

parameters = {"name": "Iphone 15", "description": "512GB, Gray space", "price": 210000.0, "quantity": 8}
new_product = Product.new_product(parameters)

print(new_product)

# Выходные данные
Iphone 15, 210000.0 руб. Остаток: 8 шт.
```

Пример №2.
Если передан продукт, который уже лежит на складе и при этом стоимость указана прежняя стоимость или меньше, то метод
выводит сообщение о том, что такой продукт уже имеется в наличии, а затем добавляет к количеству имеющегося товара
количество нового и возвращает этот продукт со старой ценой.

```
# Вызов метода
product_1 = Product("Samsung Galaxy S23 Ultra", "256GB, Серый цвет, 200MP камера", 180000.0, 5)

parameters = {"name": "Samsung Galaxy S23 Ultra", "description": "256GB, Серый цвет, 200MP камера", "price": 180000.0, "quantity": 5}

new_product = Product.new_product(parameters)
print(new_product)

# Выходные данные
При попытке добавления нового товара Samsung Galaxy S23 Ultra обнаружен аналогичный товар. Количество товаров в указанной категории было увеличено. Новая позиция не добавлена.
Samsung Galaxy S23 Ultra, 180000.0 руб. Остаток: 13 шт.
```

Пример №3.
Если передан продукт, который уже лежит на складе и при этом стоимость указана выше прежней, то метод выводит сообщение
о том, что такой продукт уже имеется в наличии, а затем добавляет к количеству имеющегося товара количество нового и
возвращает этот продукт с новой ценой.

```
# Вызов метода
product_1 = Product("Samsung Galaxy S23 Ultra", "256GB, Серый цвет, 200MP камера", 180000.0, 5, )

parameters = {"name": "Samsung Galaxy S23 Ultra", "description": "256GB, Серый цвет, 200MP камера", "price": 2100000.0, "quantity": 8}
new_product = Product.new_product(parameters)
print(new_product)

# Выходные данные
При попытке добавления нового товара Samsung Galaxy S23 Ultra обнаружен аналогичный товар. Количество товаров в указанной категории было увеличено. Новая позиция не добавлена.
Samsung Galaxy S23 Ultra, 2100000.0 руб. Остаток: 13 шт.
```

Кроме указанных выше методов имеются геттер и сеттер для аттрибута ***price(private)***.

+ геттер возвращает стоимость товара
+ сеттер позволяет изменить его стоимость
    + если новая цена равна или меньше нуля, то выводится сообщение: "Цена не должна быть нулевая или отрицательная"
    + если цена положительная и меньше старой цены, то программа предупреждает, что цена станет меньше и просит дать
      согласие на изменение цены
    + если цена положительная и равна или больше старой цены, то стоимость товара меняется автоматически

### Модуль category.py

Класс ***Category*** содержит основную информацию о категории:

+ Название категории(str)
+ Описание(str)
+ Список продуктов в данной категории(list) - private
+ Общее количество всех продуктов в данной категории(int)

А также имеются переменные для учёта ***количества категорий(int)*** и ***количества продуктов(int)***.

В данном классе реализован магический метод ***__str__***, высчитывающий общее количество продуктов в категории и
отображающий информацию об объекте класса для пользователей в формате:

```
{Название категории}, количество продуктов: {общее количество продуктов} шт."
{Название продукта}, {стоимость} руб. Остаток: {количество} шт.
```

Например:

```
Смартфоны, количество продуктов: 27 шт.
```

Метод ***add_product*** позволяет добавить продукт в категорию, ничего не возвращает.

Пример:

```
product1 = Product("Samsung Galaxy S23 Ultra", "256GB, Серый цвет, 200MP камера", 180000.0, 5)
product2 = Product("Iphone 15", "512GB, Gray space", 210000.0, 8)

category1 = Category(
    "Смартфоны",
    "Смартфоны, как средство не только коммуникации, но и получения дополнительных функций для удобства жизни",
    [product1, product2]
)

product3 = Product("Xiaomi Redmi Note 11", "1024GB, Синий", 31000.0, 14)
category1.add_product(product3)
```

Кроме указанных выше методов имеются два геттера для аттрибута ***products(private)***.

+ первый геттер возвращает список экземпляров класса Product
+ второй геттер возвращает строку с информацией о товарах с использованием магического метода str

Например:

```
Samsung Galaxy S23 Ultra, 180000.0 руб. Остаток: 5 шт.
Iphone 15, 210000.0 руб. Остаток: 8 шт.
```

### Модуль product_iterator

В классе ***ProductIterator*** реализован итератор, который будет пробегать по списку продуктов переданной ему
категории. 

Для этого прописаны два магических метода: ***iter*** и ***next***.
+ Первый возвращает итератор
+ Второй возвращает следующий элемент из списка продуктов
